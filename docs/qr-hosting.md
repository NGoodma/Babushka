# QR-бот: где живёт

Статус на 2026-11-06: QR-бот (`NGoodma/QR`) переписан под webhook и хостится на **Vercel Hobby**, а не на Render.

- Код: `api/telegram.py` в репозитории `NGoodma/QR`, работает как Python-функция Vercel без хранилища.
- Выкладка: GitHub Actions → `scripts/deploy.py`. Нужны секреты `VERCEL_TOKEN` и `TELEGRAM_BOT_TOKEN`.
- Инструкция по регистрации лежит в `docs/vercel-setup.md` того же репозитория.

Почему не Render: бесплатные 750 часов в месяц общие на аккаунт. Их почти целиком занимает expat (он не засыпает благодаря пингеру), и второй сервис без сна остановил бы оба.

Почему не Cloudflare, как у Бабушки: 10 мс процессорного времени на запрос мало, чтобы рисовать картинку, а без базы и расписания Cloudflare ничего не даёт.
