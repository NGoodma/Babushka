# Как завести бесплатный хостинг на Cloudflare для бота

Займёт 15–20 минут. Банковская карта не нужна. Токены никому не присылай, в том числе Claude. Ты сам вписываешь их в секреты GitHub (шаг 6).

## GitHub Actions: подходит, платить не нужно

- В `NGoodma/expat` Actions уже работают: последние запуски были 2026-03-30 и прошли успешно.
- На бесплатном тарифе GitHub в **публичных** репозиториях минуты Actions не ограничены, в **приватных** даётся 2000 минут в месяц.
- После переезда на Cloudflare GitHub Actions только тестирует и выкладывает бота при каждом push, это ~1–2 минуты. Бот работает на Cloudflare, так что минуты почти не тратятся. Подписчики хранятся в базе Cloudflare, а не в репозитории. Поэтому репозиторий можно сделать хоть публичным, хоть приватным, оба варианта бесплатны.

## 1. Регистрация в Cloudflare

1. Открой https://dash.cloudflare.com/sign-up и зарегистрируйся по email и паролю.
2. Подтверди email по ссылке из письма.
3. Если Cloudflare предложит добавить домен (сайт), пропусти: для ботов домен не нужен.

## 2. Включи Workers и выбери поддомен

1. В меню слева открой **Compute (Workers)** → **Workers & Pages**. В старом интерфейсе этот раздел называется просто «Workers & Pages».
2. При первом входе Cloudflare попросит выбрать поддомен `*.workers.dev`, например `ngoodma`. Тогда боты будут жить по адресам вида `babushka.ngoodma.workers.dev`.
3. Если Cloudflare предложит создать первый Worker из шаблона, это не обязательно. Главное, чтобы поддомен был выбран. Проверить можно в **Workers & Pages** → справа блок **Subdomain**.
4. Тариф оставь **Free**.

## 3. Скопируй Account ID

На странице **Workers & Pages** справа есть строка **Account ID**: это 32 символа, буквы и цифры. Сохрани его, он понадобится на шаге 6. Его же видно в адресной строке: `dash.cloudflare.com/<Account ID>/...`.

## 4. Создай API-токен для GitHub Actions

1. Справа вверху иконка профиля → **My Profile** → **API Tokens** → **Create Token**.
2. Возле шаблона **Edit Cloudflare Workers** нажми **Use template**.
3. В блоке **Permissions** нажми **+ Add more** и добавь две строки:
   - `Account` → `D1` → `Edit`
   - `Account` → `Queues` → `Edit`
4. В **Account Resources** выбери `Include` → свой аккаунт.
5. В **Zone Resources** оставь `All zones`. Доменов у тебя нет, так что это ни на что не влияет.
6. **Continue to summary** → **Create Token**.
7. Скопируй токен: Cloudflare показывает его **только один раз**. Если потеряешь, создай новый.

## 5. Создай бота в Telegram

1. Напиши [@BotFather](https://t.me/BotFather): `/newbot`.
2. Придумай имя (его видят пользователи, например «Звонок бабушке») и username, который заканчивается на `bot`.
3. BotFather пришлёт токен вида `123456789:AA...`. Это третий секрет.
4. По желанию: `/setdescription` и `/setuserpic`, это описание и аватарка, которые видны до нажатия «Начать».

Если раньше бот где-то запускался в режиме polling, его нужно остановить. Иначе он будет конфликтовать с webhook.

## 6. Секреты в GitHub (после того как появится репозиторий)

Репозиторий → **Settings** → **Secrets and variables** → **Actions** → **New repository secret**. Создай три секрета:

| Имя | Что вставить |
|---|---|
| `CLOUDFLARE_API_TOKEN` | токен из шага 4 |
| `CLOUDFLARE_ACCOUNT_ID` | Account ID из шага 3 |
| `TELEGRAM_BOT_TOKEN` | токен из шага 5 |

После этого каждый push в `main` будет сам проверять код, создавать базу и очередь (если их ещё нет), выкладывать бота и подключать его к Telegram.

## Для следующих ботов

- Шаги 1–4 делаются **один раз** на аккаунт. Этот же Cloudflare-токен подходит для всех ботов.
- Для каждого нового бота: новый бот в BotFather (шаг 5), новый репозиторий из шаблона и три секрета (шаг 6).
- На бесплатном тарифе у аккаунта до **5 расписаний** (у Бабушки одно) и до **10 баз** (у каждого бота своя). Ботам без рассылки по расписанию, вроде QR, расписание не нужно.
